26) List the member ID with highest and lowest no of books issued.
Answer:
	SELECT member_id, COUNT(book_no) AS book_count
	FROM issue
	GROUP BY member_id
	HAVING COUNT(book_no) = (
    		SELECT MAX(book_count)
    		FROM (SELECT COUNT(book_no) AS book_count
        	FROM issue
        	GROUP BY member_id
    		) AS counts
	)
	OR COUNT(book_no) = (
    		SELECT MIN(book_count)
    		FROM (
        	SELECT COUNT(book_no) AS book_count
        	FROM issue
        	GROUP BY member_id
    		) AS counts
	);

28) List the Book_No, Book_Name and Issue_date for all the books
that are issued in month of December and belong to category Database.
Answer:
	SELECT b.book_no,b.book_name,i.issue_date from books as b
	INNER JOIN Issue as i 
	ON b.book_no=i.book_no
	WHERE MONTH(issue_date)=12 and b.category='RDBMS';

30) List the Book No, Book Name, Issue_date and Return_Date for all
the books issued by Richa Sharma.
Answer:
	SELECT b.book_no,b.book_name,i.issue_date,i.return_date
	FROM books as b inner join issue as i
	on b.book_no=i.book_no
	where i.member_id=(select member_id from member
				where member_name='richa sharma');

33) List all the Issue_Details where Issue_date is not within the
Acc_open_date and Return_date for that member.
Answer:
	SELECT *
	FROM issue i
	JOIN member m
	ON i.member_id = m.member_id
	WHERE i.issue_date NOT BETWEEN m.acc_open_date AND i.return_date;

for more then 30 days.
Answer:
